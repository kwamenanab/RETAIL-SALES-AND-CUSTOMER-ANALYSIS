# RETAIL-SALES-AND-CUSTOMER-ANALYSIS
Analysis of 1000 sales shows top categories (electronics, clothing, beauty), no repeat buyers, key age groups. Recommend targeted campaigns and KPI dashboard.
EXECUTIVE SUMMARY
The analysis of 1,000 transactions shows that electronics, clothing, and beauty generate the most revenue. Monthly sales fluctuate, and orders are concentrated in specific age groups. Since only unique customers are recorded, there are no repeat buyers identified. Key recommendations include focusing promotions on top categories, capturing customer IDs to track retention, running targeted demographic campaigns, and creating an operational dashboard to monitor KPIs.
